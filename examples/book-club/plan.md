# 读书会组织助手

## 目标
自动化管理读书会的时间协调、进度追踪和讨论准备。

## 当前状态
- 读书会名称：技术读书会
- 当前书籍：《深度学习》
- 当前章节：第3章
- 成员：5人
- 上次聚会：2周前

## 任务清单

### 1. 安排下次聚会
- [ ] 收集成员可用时间
- [ ] 检查阅读进度
- [ ] 确定最优时间
- [ ] 发送确认通知

### 2. 聚会前准备
- [ ] 提前1天提醒成员
- [ ] 生成讨论问题
- [ ] 提醒进度落后的成员

### 3. 聚会后跟进
- [ ] 收集反馈
- [ ] 整理讨论要点
- [ ] 安排下次聚会时间

## 工作流程

当我醒来时：
1. 检查当前任务状态
2. 根据情况采取行动（发消息/等待回复/提醒）
3. 决定下次唤醒时间

## 注意事项
- 对未回复的人要礼貌提醒，不要催促太频繁
- 选择最多人可以参加的时间
- 讨论问题要有深度，帮助大家准备
- 对无法参加的人要表示理解并承诺分享记录
