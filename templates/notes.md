# Agent Notes

Working memory for things that aren't recoverable from messages, summaries, or the codebase.

**What belongs here:**
- Durable facts you learned about the project, the human, or the world.
- Hypotheses you want to test next session.
- Multi-session plans that won't fit in a TODO line.
- Decisions and the reasoning behind them (alternatives considered, why you chose this one).
- Friction with the cryochamber tools or protocol — surprises, ambiguities, near-misses.

**What does NOT belong here:**
- "What I did this session" — already captured by `hibernate --summary` and the outbox message.
- "Last question I asked" or "waiting for a reply" — the inbox/outbox files and the rail UI already track this.
- A chronological journal — outbox messages are the journal.

Trim when it grows. Past-you knows less than present-you, but past-you's stale notes still cost tokens every wake.
